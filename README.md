## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Layout Designer** | Position and size RaceLab widgets on a drag-and-drop canvas |
| **Profile System** | Save named dashboard layouts per simulator or race type |
| **Widget Library** | Browse all available RaceLab widgets with configuration options |
| **Quick Apply** | Switch to any saved layout before launching your sim session |
